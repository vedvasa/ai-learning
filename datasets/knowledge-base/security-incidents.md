# Report a suspected security incident

Use the **Security incident** ticket category for suspected account takeover, exposed credentials, unexpected administrator changes, or evidence that private workspace data was accessed.

## Immediate containment

Reset affected credentials, revoke unknown sessions, rotate exposed API keys, and preserve relevant audit events. Do not paste secrets, access tokens, private keys, or full customer datasets into the ticket.

## Response priority

Security incident reports are routed to the on-call security team at critical priority. The team acknowledges valid reports within four hours. Product bugs without evidence of unauthorized access follow the normal technical-support process rather than the security incident process.
