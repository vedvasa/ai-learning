# Pro plan limits

The Pro plan supports up to 50 workspace members, 100 active automations, and 100 GB of attachment storage. It includes one year of audit history and standard email support.

## API allowance

Each Pro workspace can make 120 API requests per minute. Requests over the limit receive HTTP 429 with a retry hint. The allowance is shared by all API keys in the workspace rather than assigned to each key.

## Higher limits

Enterprise plans offer negotiated member, storage, and API allowances. Support cannot temporarily raise a Pro limit. Workspace owners can contact sales from the plan page when sustained usage requires a higher tier.
