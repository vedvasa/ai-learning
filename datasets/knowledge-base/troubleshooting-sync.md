# Troubleshoot cross-device synchronization

KnowledgeDesk normally synchronizes ticket updates within several seconds. Confirm that both devices are signed into the same account and workspace before treating different ticket lists as a synchronization failure.

## Basic checks

Refresh both clients, verify network access, and install the latest supported app version. Sign out and back in only after unsent drafts have been copied elsewhere. Do not clear application data while offline because local drafts can be lost.

## Escalation details

If the problem continues for more than 15 minutes, include the workspace identifier, affected device types, app versions, approximate start time, and whether new changes appear in the web application. Never include passwords or session tokens.
