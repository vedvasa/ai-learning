# Troubleshoot the web application

KnowledgeDesk supports the two most recent stable versions of Chrome, Edge, Firefox, and Safari. An outdated browser can cause blank panels, failed uploads, or buttons that do not respond.

## Isolation steps

Reload the page, try a private browsing window, and temporarily disable extensions that modify page content or network traffic. If private browsing works, clear site data only for the KnowledgeDesk domain rather than clearing the entire browser history.

## Diagnostic information

When opening a support ticket, include the browser name and version, operating system, approximate failure time, and a screenshot without private customer data. Exported browser logs can contain sensitive data and should be provided only through the approved secure-upload request.
